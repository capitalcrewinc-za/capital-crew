Current connection

Create an admin safely

  1. Create the staff user's account in Supabase Auth.
  2. Run insert into public.staff_roles(user_id, role) values ('AUTH-USER-UUID','admin'); in the Supabase SQL editor.
  3. Sign in here using that Auth account.
  4. Use MFA and least-privilege roles for finance/compliance/support staff.
