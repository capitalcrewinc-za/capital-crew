# Capital Crew redesigned public information portal

A responsive, static website inspired by the supplied member-portal screenshot. It includes a left navigation sidebar, status header, overview cards, contribution-example grid, transaction/referral guidance, profile and verification checklist, help centre and FAQs.

## Important
This is still a public demo website. It has no login, registration, member accounts, payment processing, deposits, withdrawals, transaction history, or KYC document collection. Contribution and daily-share figures are shown as illustrative examples only and are not guaranteed returns or an offer. Replace all example figures and copy with legally reviewed, approved product information before launch.

## Run locally
Extract the ZIP and open `index.html` in a browser. Upload the extracted folder contents to your static hosting provider to publish.

## Files
- `index.html` — page structure and small interaction scripts
- `styles.css` — responsive layout and visual styling
- `assets/` — supplied Capital Crew logo images
